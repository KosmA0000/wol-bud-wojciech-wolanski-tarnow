# WOL-BUD Wojciech Wolański — Tarnów

Nowoczesna, statyczna strona demonstracyjna dla firmy **WOL-BUD Wojciech Wolański** z Tarnowa (stolarka otworowa, okna PCV i aluminiowe, drzwi, bramy garażowe, rolety, parapety, ciepły montaż).

- **Oryginalna strona**: https://wol-bud.com.pl/
- **GitHub Pages**: https://kosma0000.github.io/wol-bud-wojciech-wolanski-tarnow/
- **Branża**: Stolarka otworowa, okna, drzwi, bramy, rolety, parapety, ciepły montaż
- **Lokalizacje salonów**:
  - Salon Tarnów-Chyszów: ul. Giełdowa 5
  - Salon Tarnów: ul. Szkotnik 2B
  - Punkt Radłów: ul. Leśna 17A
- **Kontakt**: tel. 534 091 021, biuro@wol-bud.com.pl

## Cechy projektu

- Pełny katalog ofertowy zescrapowany w 100% z oryginalnej strony: 17 kategorii, 67 kart produktów, 7 usług montażowych i serwisowych.
- Interaktywne galerie produktów z obsługą przewijania strzałkami na scenie i klikalnymi miniaturkami.
- Pełnoekranowy modal Lightbox z powiększeniem zdjęć, strzałkami lewo/prawo, licznikiem i obsługą klawiatury (Esc, strzałki) oraz gestów dotykowych (swipe).
- Inteligentny powrót z podstron do sekcji wywołującej na stronie głównej (zamiast skoku na samą górę hero).
- Dedykowane przyciski „Nawiguj w Google Maps ↗” pod każdym adresem salonu.
- Zweryfikowane opinie z wizytówki Google.
- W 100% relatywne ścieżki (hosting-ready dla GitHub Pages i dowolnego serwera statycznego).
