# Testy kontraktowe (`tests/contract`)

Testy kontraktów modułów rdzenia WOL-BUD Studio (uruchamiane przez `node:test`).
Powstają w fazie 1 przed implementacją modułów i obejmują wejścia, wyjścia oraz przypadki brzegowe (polskie znaki, puste dane, długie teksty, głębokość ścieżek, kolizje adresów, istniejące przekierowania).

Pliki testowe muszą mieć rozszerzenie `*.test.mjs` i mieścić się w limicie 150 linii (twardo 200).
