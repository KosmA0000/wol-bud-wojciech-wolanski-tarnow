# Testy walidatora (`tests/validate`)

Testy niezmienników walidatora strony.
Każdy niezmiennik musi mieć przypadek pozytywny (poprawna strona przechodzi) i negatywny (celowe złamanie niezmiennika wywołuje błąd walidatora).

Pliki testowe muszą mieć rozszerzenie `*.test.mjs` i mieścić się w limicie 150 linii (twardo 200).
