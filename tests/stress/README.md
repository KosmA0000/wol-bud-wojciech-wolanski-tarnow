# Stress test asystenta AI (`tests/stress`)

Miejsce na harness oraz bank scenariuszy (`tests/stress/bank/`) w 14 kategoriach (min. 250 scenariuszy, 3 przebiegi na scenariusz).
Uruchamiane poleceniem `cd tests && npm run test:stress`.

Pliki testowe muszą mieć rozszerzenie `*.test.mjs` i mieścić się w limicie 150 linii (twardo 200).
