# Testy przepisów (`tests/recipes`)

Testy operacji wysokiego poziomu („przed → po → walidator zielony”) na kopii strony.
Każdy test sprawdza kompletność dróg dojścia według `docs/site-conventions.md` oraz brak zmian poza zadeklarowanym zakresem (diff).

Pliki testowe muszą mieć rozszerzenie `*.test.mjs` i mieścić się w limicie 150 linii (twardo 200).
